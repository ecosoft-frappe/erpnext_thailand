# Security Policy

ERPNext Thailand is the Thailand localization app for ERPNext, developed and maintained by the [Ecosoft](https://ecosoft.co.th) team. We take security issues seriously and appreciate your help in keeping ERPNext Thailand and its users safe.

## Supported Versions

Security fixes are made on the `main` branch, which supports Frappe Framework and ERPNext version 15.

## Reporting a Vulnerability

Report security issues by [opening a GitHub issue](https://github.com/ecosoft-frappe/erpnext_thailand/issues/new?template=security.yml) using the **Security issue** template.

Please include as much of the following as you can:

- Description of the issue and its potential impact
- Affected module, DocType, or API method (for example `erpnext_thailand.utils.get_address_by_tax_id`)
- Steps to reproduce (please do not post a working exploit; we will ask for details if needed)
- Versions of ERPNext Thailand, ERPNext, and Frappe Framework

## What to Expect

- We will acknowledge your report and keep you updated in the issue.
- We will investigate, fix confirmed issues, and release the fix as quickly as possible.

## Out of Scope

Issues in Frappe Framework or ERPNext core (not specific to ERPNext Thailand) should be reported to the Frappe team following the guidelines at [frappe.io/security](https://frappe.io/security).

Thank you for helping us keep ERPNext Thailand secure.
