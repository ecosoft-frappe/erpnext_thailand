### สรุปฟังก์ชั่นเพิ่มเติมของ ERPNext Thailand

1. **ภาษีไทย**:
   - **ภาษีสินค้า**: ภาษีที่เกิดขึ้นเมื่อมีการส่งสินค้าและบันทึกภาษีเมื่อออกใบแจ้งหนี้
   - **ภาษีบริการ**: ภาษีที่เกิดขึ้นเมื่อมีการจ่ายเงินค่าบริการและบันทึกภาษีเมื่อออกใบเสร็จ (บันทึก "ภาษีค้างชำระ" ที่การส่งใบแจ้งหนี้ เปลี่ยนเป็น "ภาษี" ที่แท้จริงเมื่อมีการชำระเงิน)

2. **ภาษีหัก ณ ที่จ่ายและใบรับรอง**:
   - **การหักภาษี ณ ที่จ่าย**: รองรับการหักภาษี เช่น หัก 3% สำหรับบริการ
   - **ใบรับรองภาษีหัก ณ ที่จ่าย**: การสร้างใบรับรอง PDF สำหรับผู้จัดจำหน่ายโดยอัตโนมัติ

3. **รายงานสำหรับการนำส่งให้กับกรมสรรพากร (RD)**:
   - **รายงานภาษีการซื้อและการขาย**: สร้างรายงานที่จำเป็นสำหรับการนำส่งภาษี
   - **รายงานภาษี 0%**: เช่นการส่งออกและได้รับยกเว้นภาษี 
   - **รายงานภาษีหัก ณ ที่จ่าย (PND)**: รองรับการนำส่งรายงาน PND3 และ PND53

4. **ใบวางบิล**:
   - วางบิลทั้งฝั่งซื้อและฝั่งขาย เป็นการสรุปใบแจ้งหนี้ที่ต้องจ่ายให้กับคู่ค้า

5. **การจัดการเงินมัดจำ (Deposit Invoice)**:
   - **การสร้างใบแจ้งหนี้เงินมัดจำ**: อนุญาตให้สร้างใบแจ้งหนี้มัดจำสำหรับการขายและการสั่งซื้อ
   - **การจัดสรรเงินมัดจำ**: อนุญาตให้มีการจัดสรรเงินมัดจำอย่างแม่นยำหรือตามอัตโนมัติให้กับใบแจ้งหนี้

6. **การตั้งค่าภาษีไทย**:
   - **การตั้งค่าภาษีที่ปรับแต่งได้**: ตั้งค่าบัญชีภาษีให้สอดคล้องกับกฎระเบียบของไทย
   - **การจัดการที่อยู่ภาษีของบริษัท**: เพิ่มฟิลด์สำหรับการจัดการที่อยู่ภาษี

7. **ที่เกี่ยวกับภาษาไทย**:
   - **จำนวนเป็นข้อความภาษาไทย**: แปลงจำนวนตัวเลขเป็นข้อความภาษาไทยบนฟอร์ม
   - **รูปแบบวันที่ไทยเต็ม**: แสดงวันที่ในรูปแบบปฏิทินไทยบนฟอร์ม

9. **การแลกเปลี่ยนสกุลเงิน**:
   - **การเชื่อมต่อกับธนาคารแห่งประเทศไทย**: ดึงอัตราแลกเปลี่ยนสกุลเงินจากธนาคารแห่งประเทศไทย

9. **การพิมพ์เอกสาร**:
    - ตัวเลือกการมีสำเนาเพิ่มเติม เช่น ต้นฉบับ สำเนา
    - การกำหนดให้ระบบเลือก Print Format ให้อัตโนมัติตามประเภทเอกสาร

10. **การดึงที่อยู่สำหรับหน่วยงานไทย**:
    - **นำเข้ารหัสไปรษณีย์ไทย**: จัดการที่อยู่โดยใช้ข้อมูลรหัสไปรษณีย์
    - **การค้นหาที่อยู่ตามหมายเลขประจำตัวผู้เสียภาษี**: ดึงที่อยู่จากหมายเลขประจำตัวผู้เสียภาษี

11. **ใบกำกับภาษีอิเล็กทรอนิกส์และใบรับอิเล็กทรอนิกส์ (e-Tax Invoice & e-Receipt)**:
    - **ลงนาม e-Tax**: ส่งใบแจ้งหนี้ ใบลดหนี้ ใบเพิ่มหนี้ และใบเสร็จรับเงินจากลูกค้า ไปลงนามผ่าน Frappe e-Tax server ([etax_inet](https://github.com/ecosoft-frappe/etax_inet)) จากฟอร์มหรือเลือกหลายใบจากหน้ารายการ (เกิน 10 ใบจะลงนามในเบื้องหลัง เสร็จแล้วผลขึ้นบนหน้าจอและแจ้งทาง Notification)
    - **ไฟล์และประวัติ**: แนบไฟล์ PDF/XML ที่ลงนามแล้วกลับมาที่เอกสาร และเก็บทุกคำขอไว้ใน Integration Request
    - **ใบแทนและใบลด/เพิ่มหนี้**: ออกใบแทน (Create Replacement) ของเอกสารที่ลงนามแล้ว (Sales Tax Invoice ของเอกสารเดิมถูกยกเลิกไปด้วยและสร้างใหม่เมื่อ submit ใบแทน) และระบุเหตุผล (Purpose Code) ของใบลดหนี้/ใบเพิ่มหนี้
    - **ภาษีขายที่ยังไม่ถึงกำหนด (บริการ)**: ใบแจ้งหนี้ไม่ใช่ใบกำกับภาษี ให้ลงนามเป็น 380 (หรือไม่ลงนาม) และลงนามใบเสร็จเป็น T03 ซึ่งเป็นใบกำกับภาษีของยอดที่รับชำระ ใบลด/เพิ่มหนี้ของใบแจ้งหนี้นี้ไม่ส่งเป็น e-Tax
    - **ภาษีและค่าใช้จ่าย**: VAT ต้องคำนวณจากยอดสุทธิ (On Net Total) ค่าขนส่งหรือค่าบริการในตารางภาษีส่งเป็นบรรทัดแยกที่ไม่มี VAT ใบแจ้งหนี้ส่งในสกุลเงินของเอกสาร ราคาต่อหน่วยส่งเป็นราคาก่อน VAT แม้ราคาในเอกสารรวม VAT
    - **อัตรา VAT**: อ่านจากแถวภาษีของเอกสาร (หรือ Item Tax Template ของสินค้า) ไม่ได้กำหนดตายตัวที่ 7% สินค้ายกเว้น VAT ให้ใช้ Item Tax Template ที่ติ๊ก Not Applicable จะส่งเป็น FRE ส่วน Template 0% ส่งเป็น VAT 0% (อัตราศูนย์ เช่น ส่งออก) ถ้าอัตรา VAT เปลี่ยน ให้แก้ Sales Taxes and Charges / Item Tax Template และช่อง Tax Rate ของบัญชีภาษีขาย (รวมบัญชีภาษีขายที่ยังไม่ถึงกำหนด)
    - **การตั้งค่า**: eTax Connection ต่อบริษัท (Server URL, API Key/Secret, การส่งอีเมล, วันที่ล็อกการออกใบแทน) และ eTax Document Type ของแต่ละประเภทเอกสาร ดูรายละเอียดใน README.md หัวข้อ "For e-Tax setup"
